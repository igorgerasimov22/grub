# Работа с GRUB

## Включить отображение меню GRUB
Для отображения меню ```GRUB``` нужно отредактировать конфигурационный файл ```/etc/default/grub```
```bash
#GRUB_TIMEOUT_STYLE=hidden #Коммунтируем строку скрывающее меню GRUB
GRUB_TIMEOUT=10 #Выставляем задержку отображения меню GRUB
```
Обновляем конфигурацию GRUB
```bash
update-grub
```
Перезагружаем систему
```bash
reboot
```
При следующей загрузке мы увидим меню GRUB

## Как попасть в систему без пароля
### Изменение параметров загрузки ядра
1. Запускаем ВМ в VirtualBox
2. Выбираем ```Ubuntu``` и нажимаем кнопку ```e```
3. В конце строки начинающийся с ```linux``` дописываем ```init=/bin/bash```
4. Нажимаем ```Ctrl+X``` для загрузки системы
5. Так как системы загружена в ```Read-Only``` режиме нам необходимо изменить на ```Read-Write``` коммандой:
```bash
mount -o remount,rw /
```
6. Теперь меняем пароль:
```bash
passwd user
```
7. Перезагружаем систему и проверяем новый пароль

### Изменение пароля через Recovery mode
1. Запускаем ВМ в VirtualBox
2. В меню ```GRUB``` выбираем меню ```Advanced options for Ubuntu```
3. Выбираем ядро Ubuntu с пометкой ```(recovery mode)```
4. Для монтирования файловой системы в режиме ```Read-Write``` выбираем пункт ```network``` и подтверждаем монтирование файловой системы ```<Yes>```
5. Загружаем систему без пароля выбрав пункт меню ```root```
6. Теперь меняем пароль:
```bash
passwd user
```
7. Перезагружаем систему и проверяем новый пароль

## Переименование volume group
1. Смотрим имя ```volume group``` в стобце ```VG``` командой:
```bash
vgs
```
2. Переименовываем ```volume group```:
```bash
vgrename ubuntu-vg new-vg-name
```
3. Правим ```/boot/grub/grub.cfg```. Везде меняем старое наименование ```ubuntu-vg``` на новое ```new-vg-name```
4. Перезагружаем систему:
```bash
reboot
```
5. Проверяем что ```volume group``` переименована:
```bash
vgs
```
